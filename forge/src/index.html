◈Default / Required: Isolated Rust & JavaScript / TypeScript Builds
NOT CHECKED

Both Rust build modes compile in Docker. Development stages filtered local sources; production delegates Git checkout and Docker orchestration to NEAR's official reproducible-wasm mode. WASM artifacts require explicit approval; signer keys must be disconnected.

Development accepts locally saved files. Production requires a clean committed Git project, tracked Cargo.lock, reproducible_build metadata and a verified official cargo-near Windows launcher that orchestrates Docker. JavaScript / TypeScript uses development mode only. Production releases block Cargo.toml passed_env settings and strip credentials, proxy secrets, and other custom environment variables from host build processes.

RUST PRODUCTION TOOLCHAIN
For the production mode only: the official cargo-near Windows command launches the NEAR reproducible Docker build. Setup installs verified Rust/cargo-near tooling, but never compiles the project on Windows.
Requires Docker Desktop running Linux containers. If Docker is missing or stopped, Forge blocks compilation instead of using Windows tools. First build downloads a large toolchain image.

Development compilation runs offline after fetching dependencies. Production mode delegates Docker orchestration and network behavior to official cargo-near. Neither mode audits source security. The archived near-sdk-js compiler may fail even in Linux.
