◈Isolated Rust & JavaScript / TypeScript Builds
NOT CHECKED

Recommended for projects from GitHub. Forge copies selected source into a temporary workspace, builds inside restricted Docker Desktop Linux containers, and imports only the WASM you explicitly approve. The original project and signing keys are never mounted.

Requires Docker Desktop running Linux containers. First build downloads a large toolchain image. A native Windows confirmation is always required.

Dependency downloads temporarily require container network access; the compilation stage runs offline. Containers are not perfect isolation. Only compile projects you have reviewed. Official near-sdk-js is deprecated and may fail even in Linux.
