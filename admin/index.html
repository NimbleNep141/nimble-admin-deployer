Only the parent account can create the selected child account. The deployment deliberately adds no access keys to the factory. Account creation is not auto-retried after wallet redirects or failures.

One-time owner-authorized contract call that installs the fixed v0.1 token code.

Not checked

Irreversible in v0.1. The on-chain contract restricts this call to the configured owner. Installation is blocked if the template is already installed or the factory has unexpected access keys.
